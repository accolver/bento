# Proposal: Accessibility

## Why

All users deserve access to Bento, including those using screen readers,
requiring high contrast, or needing alternative input methods. Accessibility
compliance (VoiceOver, TalkBack) is both ethical and required for app store
compliance.

## What Changes

- Audit all widgets for semantic labels
- Add comprehensive accessibility labels
- Test with VoiceOver (iOS) and TalkBack (Android)
- Add high contrast mode for outdoor use
- Ensure focus order and keyboard navigation
