# Proposal: Cloud AI Providers

## Why

While local AI handles simple tasks, complex commands benefit from more capable
cloud models. Supporting OpenAI, Anthropic, and Google gives users choice and
access to state-of-the-art models when needed, with explicit consent for data
transmission.

## What Changes

- Implement OpenAI provider (GPT-4)
- Implement Anthropic provider (Claude)
- Implement Google provider (Gemini)
- Add secure API key management
- Implement privacy consent flow
- Handle rate limits and errors gracefully
- Support streaming responses

## Capabilities

### New Capabilities

- `openai-provider`: GPT-4 integration
- `anthropic-provider`: Claude integration
- `google-provider`: Gemini integration
- `consent-flow`: Privacy-first cloud access
