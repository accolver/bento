# Proposal: Theme System

## Why

Users have preferences - dark theme at night, light theme in sun. A proper theme
system with terminal color schemes (Dracula, Solarized, Nord) lets users
customize their experience and improves usability across lighting conditions.

## What Changes

- Define BentoColors for dark theme (default)
- Define BentoColors for light theme
- Implement theme switching with persistence
- Add terminal color scheme support
- Support system theme following
