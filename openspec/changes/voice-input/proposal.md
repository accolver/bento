# Proposal: Voice Input

## Why

Sometimes typing isn't practical - driving, hands dirty, accessibility needs.
Voice input lets users speak commands naturally, which then route through the AI
Ghostwriter for conversion to CLI syntax.

## What Changes

- Integrate speech_to_text package
- Add microphone button to command ribbon
- Implement voice-to-text flow
- Route transcription through AI Ghostwriter
- Handle continuous dictation mode
